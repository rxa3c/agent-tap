# WorkBuddy live dashboard evidence

Screenshots of the agent-tap dashboard (1440px wide) served from a throwaway
trace database seeded with **made-up** WorkBuddy records. They contain no real
conversation, prompt or account data.

- `dashboard-overview.png`: the session list with a live `workbuddy` session.
- `workbuddy-session-live.png`: the session detail. Turn 1 is WorkBuddy's
  `wb-lite` title request. Turn 2 is a finished reply with a collapsed
  "Thinking" block. Turn 3 is still streaming ("Generating"), with its thinking
  text shown open before any answer text arrives. Each request box starts with
  the system prompt.

Real WorkBuddy 5.9.3 and 5.11.3 conversations were checked by hand on macOS
and are not stored in the repository.
